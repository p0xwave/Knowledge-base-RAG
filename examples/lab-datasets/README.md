# Документы для ручной проверки лаборатории

Все сведения вымышлены. Это небольшой корпус об учебной лаборатории «Орбита»,
не правила вашего университета и не ограничения реального сервиса.

1. Создайте датасет «Орбита» и загрузите одновременно три файла из `v1`.
2. Проверьте список файлов, номер версии и скачивание оригиналов.
3. Нажмите «Новая версия» и загрузите три файла из `v2`.
4. Переключайтесь между версиями и сравнивайте файлы. В новой редакции изменены
   часы консультаций, срок проверки заявки, квота, хранение черновиков и число эпох.
5. Для проверки нескольких независимых датасетов загрузите `v1` ещё раз через
   «Загрузить датасет», задав другое название, например «Контрольный корпус».

Контрольные отличия:

| Правило | v1 | v2 |
|---|---|---|
| Проверка заявки | 2 рабочих дня | 1 рабочий день |
| Консультации | Вт/Чт, 15–17 | Пн/Ср, 16–18 |
| Квота студента | 5 ГБ | 8 ГБ |
| Хранение черновиков | 14 дней | 28 дней |
| Эпохи в начальном плане | 2 | 3 |

Когда подключите генератор, можно создать две синтетические версии с seed 42 и 7,
сравнить manifest и сохранить планы LoRA с разными базовыми моделями.
Сейчас генерация выключена по вашему выбору, а обучение реализовано как план.

Этот README загружать в датасет не нужно: он содержит сразу обе редакции правил.
